# 疑似データ(不適合報告書 117件・完全架空)

> **このディレクトリのデータはすべて疑似データ(プログラム生成の架空データ)です。**

セミナー用に `generate_mock_data.py` がテンプレート+乱数で合成したもので、
実在の企業・人物・製品・実際の不良事例とは一切関係ありません。
客先(翠峰重工業〜霞岡バルブ工業)・作業者名(一般的な姓)・部品番号・不具合内容の文章はすべて架空です。

## 内容

| パス | 内容 |
|---|---|
| `generate_mock_data.py` | 生成スクリプト(乱数シード42固定 → 再実行しても同一の出力) |
| `defect_reports.csv` | 報告書117件(バックエンド初回起動時の自動シードに使用) |
| `forms_xlsx/KZ25-0001〜0117.xlsx` | 不適合報告書のExcel帳票(全117件、様式QF-07-03)。帳票取り込み機能のデモ用 |
| `forms_pdf/KZ25-0001〜0010.pdf` | 同PDF版(先頭10件)。AI抽出(vision)のデモ用 |

## 再生成

```bash
# リポジトリルートで(要 openpyxl / reportlab / pandas)
.venv/bin/python data/generate_mock_data.py
```

## データの特徴(docs/03_データモデル設計書.md §4 準拠)

- 期間: 2025-04-01〜2026-03-31 の1年間
- 現象は上位3種(穴位置不良・寸法不良・キズ)で約6割 → パレート図が意味を持つ分布
- 重要度: critical/high/medium/low の混合、再発フラグ 約15%
- 客先は架空の「翠峰重工業〜霞岡バルブ工業」、作業者は一般的な姓のみ
