## AC 以外で気づいたこと（直していない）

- `GET /api/masters/unknown` の本文は FastAPI 標準の `{"detail":"Not Found"}`（英語）。AC-v11-06 は404だけを求めるので合格だが、04 §1 の「誤りの応答は日本語」とは合わない。
- 一覧の絞り込みは、幅1280px では「並び順」が2行目に回る（05 の画面の図では1行）。
- 写真03の「期間（開始日）」のラベルは、入力欄の選択を外した直後でアンバー色のまま写っている（見た目だけ）。
