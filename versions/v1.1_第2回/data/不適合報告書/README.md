# 模擬不良報告書（Excel）— 架空の霧沢精機・110件

アプリを作る「元になるデータ」です。第2回では、この Excel の束を Claude Code に読ませて、何が書いてあるかを調べ、仕様書を作るところから始めます。

- **会社と期間：** 架空の株式会社霧沢精機 霧沢工場（品質保証課）の不適合報告書110件です。発生日は2025年4月〜2026年3月です（最後は2026年3月15日）。
- **すべて架空です。** 会社・客先・人名・部品番号・金額は、実在の企業や人物と関係ありません。
- **フォルダ：** 発生年月ごとのフォルダ（`2025-04/` 〜 `2026-03/`）に、1件1ファイル（`KZ25-0001.xlsx` など）で入っています。
- **例アプリとの関係：** 例アプリ DefectReport AI の元データ（`example_app/data/defect_reports.csv`）と同じ内容です。CSV は、この帳票を1件1行に書き写したものに当たります。

## 様式は2種類（途中で改訂された）

| | 改訂B（旧様式） | 改訂C（新様式） |
|---|---|---|
| 対象 | 発生日が2025年9月以前（48件） | 発生日が2025年10月以降（62件） |
| 題名 | 不良報告書 | 不適合報告書 |
| 項目名の例 | 管理No.・発行日・工程・設備・図番・品名・あるべき姿・処置状況 | 報告書番号・報告日・発生工程・使用機械・部品番号・部品名称・良品状態・状態 |
| 数量 | 「不良数 / 加工数」を1つの欄に記入（例 1 / 9） | 加工数と不適合数を別の欄に記入。不良率は計算式 |
| 選択する項目 | 文字で記入（重大度「高」、4M「方法」） | ■／□ で選ぶ（重要度・現象・4M・状態など） |
| 費用 | 項目名の下に金額。合計は手入力 | 項目名の右に金額。損失合計は計算式 |
| 日付の表示 | 2025/5/14 | 2025年11月1日（中身はどちらも日付の値） |

仕様書を作るときは、この違い（項目名の揺れ・数量の書き方・選択肢の表し方）をどう1つのデータにまとめるかを決める必要があります。

  - 完了：承認まで
