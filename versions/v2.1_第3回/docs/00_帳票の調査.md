# DefectReport AI — 帳票の調査

> 仕様書 v2.1（第3回の終わり）。前の版から変わったところは `変更点.md`。

本書は、アプリの元になる不適合報告書の Excel(110件)を調べた結果をまとめる。様式・項目とセル・表記の揺れ・欠損・件数と期間を、110 ファイルすべてを読んで数えた値で書く。要件は `01_要件定義書.md` に書く。

---

## 1. 対象と読み方

| 項目 | 内容 |
|---|---|
| 対象 | `data/不適合報告書/` の Excel(.xlsx)110 ファイル。講座の配布資料 `模擬不良報告書_Excel/` と同じもの |
| 置き方 | 発生年月のフォルダ(`2025-04/` 〜 `2026-03/` の12個)に 1 件 1 ファイル。ファイル名は報告書番号(例 `2025-04/KZ25-0001.xlsx`) |
| 読み方 | openpyxl でセルを読む(読み取りのみ。原本は変更しない)。数式の欄は、数式と計算結果の両方を読む |
| 元データとの関係 | 押印欄と部署を除く全項目が、110 件すべてで例アプリの元データ `data/defect_reports.csv`(110行)と一致する。CSV は帳票を 1 件 1 行に写したものに当たる(対応は 4 章) |
| 架空のデータ | 会社(株式会社霧沢精機 霧沢工場 品質保証課)・客先・人名・部品番号・金額はすべて架空 |
